## pos-BackOffice-rewrite
* Make sure you create an `Config.tsx` file in the `utils` folder

## Getting Started
* npm
    * Run `npm install`
    * Run `npm run dev` to start the web application

* yarn
    * Run `yarn install`
    * Run `yarn dev` to start the web application

## Deploy the web application
* npm
    * Run `npm install` to install the necessary packages
    * Run `npm run build` to build the web application
    * Merge to specific branch will deploy the web application to Amplify automatically

* yarn
    * Run `yarn install` to install the necessary packages
    * Run `yarn run build` to build the web application
    * Merge to specific branch will deploy the web application to Amplify automatically
